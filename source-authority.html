Whose request guides the next action?

Source-authority guidance fixed the known shuttle error, but did not reliably improve new cases or outperform the no-summary reference. It remains an optional experimental configuration.

One change to the actor

The optional agent-led-source-authority configuration appends guidance to each already scheduled actor request: resolve task claims using participant speech, attribution and chronology; distinguish interpretations from requests; retain genuine changes, conditions, withdrawals and renewed acceptance. It adds no model call, required answer format or semantic gate. The default harness is unchanged.

Both actors receive the same full conversation, arrived fictional facts and 16 captured tools. Only the added system guidance differs. Each is tested with correct and deliberately incorrect summaries; an ordinary actor without a summary provides a shared reference. The existing summary-attribution intervention is not enabled.

A scope error is an observable unsupported expansion, rejection of accepted work, wrong task ownership or changed condition. Re-asking for already settled acceptance counts in the main metric. Only pure re-approval errors are excluded in the sensitivity column; coexisting errors remain. One legal intermediate action need not complete every subtask. “No error” does not establish understanding or delivered help.

What the comparison shows

A known error was corrected; that is not a general improvement

With an incorrect summary, the ordinary actor requested the explicitly deferred Canal Shuttle search. The guided actor kept that option separate. On exposed cases, definite scope errors fell from 2/12 to 1/12, with one additional uncertain output in each arm. Excluding pure re-approval questions changes these counts to 1/12 and 0/12.

New cases expose both a fix and a regression

Under incorrect summaries, new-challenge scope errors were 2/12 for the ordinary actor and 2/12 plus one uncertain output for the guided actor. Guidance stopped the premature Birch check, but started the withdrawn Meadow lookup. Both actors still dismissed Owen's explicit current Pine request as someone else's historical request.

A simpler reference remains stronger on these short inputs

The no-summary reference had no observed scope errors in either 12-case split. Both actors also had no scope errors with correct summaries. Every comparison contained the full original dialogue; this does not establish that summaries can be removed from long conversations. Guidance added 331 input tokens per actor call without adding a model call.

Limits and next work

One greedy call per cell, one local Qwen2.5 14B Q4_K_M model, fictional short conversations, and independent AI scoring. New materials were written for these mechanisms, with explicit state changes; they are not natural conversations or implicit-acceptance validation. Guidance also increases context length; no length-matched placebo isolates that effect. No tools execute here, so no delivered-success, real-ASR or human-benefit claim follows.

  • Keep the candidate optional. Do not promote it based on the exposed shuttle fix or software-test results.
  • Investigate why the actor acknowledges a withdrawal yet requests that lookup, and why a second participant's present request is still treated as old background. Compare evidence placement and task-source attribution using separate frozen conditions.
  • Evaluate the next promising change in a full replay with executed tool receipts, changing conversation state, budget and delivered-answer scoring. Maintain a no-summary reference only where the original context is fully available.
  • Repair the separately identified mismatch between conversation event types used by query extraction and retrieval, then verify its integration without presenting that software fix as intention-quality evidence.
